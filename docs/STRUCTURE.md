# Source layout

| Original path | New path |
| --- | --- |
| `src/landmarks extraction.ipynb` | `notebooks/01_extract_landmarks.ipynb` |
| `src/lightweight-ttstgcn-300.ipynb` | `notebooks/02_train_lightweight_ttstgcn.ipynb` |

Research notebooks belong in `notebooks/`; generated data and models belong in local `data/` and `outputs/` directories. Source model and training cells are retained. Some original notebooks contain several experiments; select the intended configuration rather than assuming every block belongs to one run.
